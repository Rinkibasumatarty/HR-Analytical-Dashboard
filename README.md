# HR Analytics Dashboard - Power BI

##  Project Overview

The HR Analytics Dashboard is an interactive Business Intelligence solution developed using Microsoft Power BI to analyze workforce data and provide valuable insights into employee performance, attrition, attendance, salary distribution, and workforce demographics.

The dashboard enables HR managers and business leaders to monitor key HR metrics, identify employee retention issues, evaluate workforce performance, and make data-driven decisions.

This project demonstrates practical skills in data cleaning, data modeling, DAX, Time Intelligence, KPI development, and interactive dashboard design.

# Business Problem

Human Resource departments manage large volumes of employee data, making it difficult to manually analyze workforce performance and identify employee-related trends.

Organizations often struggle to:

- Monitor employee attrition
- Track employee attendance
- Analyze department performance
- Compare salary distributions
- Measure workforce demographics
- Identify high-risk departments with high turnover
- Improve employee retention
- Support HR decision-making using data

This dashboard solves these challenges by providing an interactive and centralized HR reporting solution.
